# Astro

A daily tarot web app by Midnight Poetry Studio. You can draw a 1-card reading, or a 3-card spread where each of the Major Arcana is paired with a Minor Arcana "clarifier". Each reading comes with written meanings, a journal, and optional paid readings (an AI insight or a human reader).
